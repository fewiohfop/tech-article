# 事实核验与来源标注规范

## 一条底线

**可以进行合理推测，不可无端猜测。事实就是事实，推测就是推测，不可将推测当成事实。**

宁可少写一条，不可写错一条。数字、参数、日期、机构名是最容易出错也最容易被截图打脸的地方。

---

## 三级标注

### L1 共识（不必标来源）

满足任一即可：

- 官方直接发布：官网、财报电话会、官方博客、官方公告、官方技术报告
- ≥3 个相互独立的来源口径一致

处理：正常写入正文，不加限定词，不标来源。给「全网都知道」的事加一堆「据 XX 报道」，
反而显得心虚、降低可读性。

### L2 据报道（一句带过）

1–2 个可信来源（主流科技媒体、正规财经媒体、有署名记者的报道）。

处理：正文写「据报道」「XX 称」，不需要展开来源背景。

### L3 爆料 / 传闻（必须显式标注）

- 社交媒体帖（X / Reddit / 微博）、社区流传截图
- 单一匿名源、「消息人士」
- 泄露的参数、定价、基准跑分
- 厂商自述的效果数据

处理：

1. 图文里必须出现明确警示，如「未经官方确认」「据爆料」「非官方数据」
2. **不得写进标题**
3. 最好集中放一页，页首加警示框，而不是混在正文里当事实讲
4. 如果有独立来源提出质疑，把质疑一并写出

---

## 必须做的三个动作

### 1. 主动找反方

原文说得越绝对，越要检索它的反面。

检索式参考：`<对象> 质疑 / 未经验证 / 不能证实 / 反驳 / 反例 / 争议`

典型情形：原文写「碾压竞品」，实际多半是社区个别 Prompt 的单次对比，
不是统一受控评测。这类结果只能作为能力信号，不能外推成总体排名。

### 2. 降级绝对化表述

原文常用「碾压」「彻底」「完胜」「壮士断腕」这类修辞。核验后若支撑不足：

| 原文 | 核验后改为 |
|---|---|
| 碾压竞品 | 在这组测试中超过竞品；或：单项 Demo 表现更好 |
| 性能大幅超越 | 报告显示在该项基准上领先（并标注是否官方） |
| 公司已放弃 X | 官方称 X 仍在测试中，另有报道称已搁置（两种说法并存） |
| 已确认将 X 月发布 | 官方未给日期；行业预测集中在 X 月 |

### 3. 保留对原文不利的信息

原文里那些「当然也有槽点」「某方面仍不如竞品」「同时也存在质疑」的句子，
**是文章可信度的一部分，不是废话**。删掉它们会让笔记变成不实宣传。

## 分歧怎么处理

多个来源互相矛盾时：

- **并列写出**两种（或多种）说法，标明各自依据
- 不挑一个当定论
- 不取平均
- 不自行编造一个调和版本

例：检查点代号有 barium-b / Checkpoint 2 / Argon 多个版本在传 → 直接写「代号说法不一，有 X、Y、Z 三个版本」。

## 来源署名：标不标、标的在哪（用户 2026-09-28 问过）

**用户问**：「封面一定要标来源吗？删掉会不会有风险？」

**结论：保留来源，但移到末页；删掉不算违法，但收益为零、风险不为零。**

判断依据不在「标不标」，而在**是二次创作还是直接搬运**：

- 法理上，标明来源是「合理使用 / 二次创作」的重要抗辩要素。不标，被投诉搬运时更被动。
  个人非商业用途风险本来就低，标注是低成本风控。
- 平台层面，小红书治理的是「搬运和洗稿」。本 skill 产出的是**重制图文**
  （自己的结构、观点、卡片），标来源是加分项。
- **真正决定风险的是**：整段照抄原文 → 标了也有风险；信息重组 + 独立表达 → 不标也基本安全。
- 有个比文字标注更关键的点：**自绘卡片、不用原媒体的图**。
  图片侵权比文字更容易被投诉，这一点必须守住。
- 素材来自外媒时，标注必要性更高（跨语言搬运更明显）。

**放置位置（用户明确要求，2026-09-28 二次收紧）：**

- ❌ **不放封面** —— 封面是抓点击的位置，塞来源名会削弱视觉焦点
- ✅ **统一放最后一页底部，只写一行媒体名**：

  ```
  来源：36氪 · 新智元
  ```

  **不附加原标题、日期、免责说明。** 用户原话：「来源：36氪 · 新智元 就可以了，不需要写那么多」。
  卡片模板里对应 `.in-foot`。
- **L3 的「未经官方确认」警示不写在末页脚注**，照常放在对应内容页
  （如参数页页首的琥珀色警示框）——合规不减，也不啰嗦。
- 末页脚注会挤压内容高度：一行脚注约 57px，配 `gap:42px` 刚好；两行则需把 gap 降到 30px 左右。
  改完必须肉眼复核末页。

**别把来源当免责牌用。** 标注不等于可以照抄。

## 找不到时的表述纪律

查不到就只能说三件事：**查了哪些位置 / 用了什么方法 / 还剩什么没查**。

**绝不用推演出来的原因填补空白。**

「我没找到」不等于「这个东西不存在」，不得升格。
