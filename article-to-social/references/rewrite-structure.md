# 结构重组：怎么把「改写」做成「重制」

用户 2026-09-28 明确要求：

> 流程里面本身有查找验证阶段，是否可以收集之后对原文内容结构进行优化、总结归纳。洗稿性没有那么强。

这条要求的本质是：**不要顺着原文的段落顺序换词，而要把信息拆散后按自己的逻辑重新组装。**

---

## 零、抖音特有前提：命门在「划到最后一张」

## 零、抖音的特有前提：图文的命门在「划到最后一张」

小红书是「读」，抖音是「划」。二者衡量的东西不同：

| | 小红书 | 抖音图文 |
|---|---|---|
| 核心指标 | 完读率 / 收藏 | **划到最后一张的比例** |
| 系统能观察到的 | 停留、点赞、收藏 | 停留时长、**划到第几张**、有无回划、有无点开评论 |
| 内容编排的作用 | 辅助阅读 | **本身就是核心变量**——同样 9 张图换个顺序，数据能差好几倍 |

由此推出两条硬约束，**在重排时不可违反**：

### 约束 1：第 2 张必须独立成立，且要有新信息

第 1 张决定他点不点，**第 2 张决定他划不划第 3 张**。
如果第 2 张只是第 1 张的补充说明（「上一条说的是……下面继续说」），这条图文基本到此为止。

✅ 正确：第 2 张直接给一个**新的、能自己站住的结论或数字**
❌ 错误：第 2 张是第 1 张的续写、展开、举例

### 约束 2：每张都要能单独看懂

用户可能从任意一张滑入，也可能只看 2–3 张就走。
所以每张卡片必须自带完整的小标题，**不能依赖上一张建立的上下文**。

✅ 正确：`水上飞机起飞压过 Opus 5.5`（自带主语）
❌ 错误：`它的表现如何`（依赖上一张）

## 一、先分清三种做法（风险从高到低）

| 做法 | 特征 | 判定 |
|---|---|---|
| **洗稿** | 保留原文段落顺序、保留原文小标题、只做同义替换 | ❌ 高风险的搬运 |
| **摘要** | 压缩原文、顺序不变、观点不变 | ⚠️ 仍是衍生，只是短了 |
| **重制** | 打散事实点、按新逻辑重排、补入原文没有的信息 | ✅ 正在采用的做法 |

判断标准只有一条：**把原文和你做的笔记并排放，能不能一眼看出结构不同。**
看不出来，就是洗稿。

---

## 二、三步走：拆 → 重排 → 重述

### 第一步：拆（在 ② 提纯阶段完成）

把事实内核拆成**彼此独立、可单独成立**的信息点，丢掉原文的叙事顺序。

拆完的清单长这样（示例：GPT-6 Astra）：

```
- AA 智能指数 61 分（v4.1.1，9/3 口径）
- 与前代 Sol 持平，榜上第 5
- 定价 $10/$50，为前代 2.5 倍
- 每任务成本贵 75%
- 幻觉率 92% → 51%
- Coding Agent 67 分
- 上下文 105 万 tokens
- ARC-AGI-3：中立接口 62.7% / 自建框架 99.9%
- AA 在两周内三度更新评测方法（v4.1.1 → v4.2 → v4.3）
- Opus 5.5 于 9/22 以 58 分登顶
- Brockman 称「AGI 时代已开始」，Chollet / Marcus / Konwinski 反驳
```

清单一旦独立于原文，后面的顺序就由你定。

### 第二步：重排（挑一个骨架，不要用原文的骨架）

按选题类型选骨架。以下五套是常规可用的：

**① 结论先行型**（适合评测、数据类）
```
结论 → 三条支撑数据 → 反方或例外 → 对读者的实际影响
```

**② 对比反转型**（适合争议、打脸、辟谣类）
```
大家的印象 → 但事实是 → 为什么会有这个反差 → 该怎么理解
```
> Astra 那篇用的就是这套：印象是「61 分与前代持平、毫无进步」，
> 反转是「两天后评测机构自己改了标准，同一条模型变成并列第一」。

**③ 时间线型**（适合事件演进、公司动向）
```
起点 → 关键节点（带日期）→ 当前状态 → 下一步的确定信号
```

**④ 问答型**（适合知识密度高的干货）
```
读者最想问的 4 个问题，一问一段
```
> 问题要从读者视角拟，不要用原文的小标题当问题。

**⑤ 数字拆解型**（适合单点数据冲击）
```
先抛最刺眼的数字 → 这个数字怎么算出来的 → 数字背后是什么 → 数字之外的观察
```

**再定前两张（抖音特有，最重要的一步）：**

**再定前两张（抖音特有，最重要的一步）：**

- **第 1 张（封面）**：抛钩子。可以是最大的反差、最刺眼的数字、或最反直觉的结论。
  **不要**在第 1 张把结论说完——说完他就不划了。
- **第 2 张**：必须是第 1 张**没有**的信息，而且要能独立成立。
  最稳的写法是「第 1 张提反常识的表象，第 2 张给支撑它的第一组硬数据」。

### 第三步：重述（自己的句式）

- **句子重写，不只是换词。** 原文「该公司于第三季度实现了显著增长」，
  不要写成「这家公司第三季度出现明显增长」，而要写成「三季度，这家公司的收入涨得比预期快」。
- **连接词换掉。** 原文用「因此/从而/进而」的位置，改成口语的方向词（「所以」「结果」「但问题是」）。
- **段落长度打散。** 原文一段 5 句，重排后可以变成 2 句 + 2 句 + 1 句。

## 三、信息增量：重制与洗稿的分水岭

**重制之所以不算洗稿，靠的是「你有原文没有的东西」。** 增量有三个正当来源：

### 1. 核验阶段查出来的信息（最主要）

③ 事实核验不是走过场，它天然产出原文没有的内容：

| 产出 | Astra 那篇的实际例子 |
|---|---|
| **版本与时点** | 原文只说 61 分；核验查出 AA 在两周内三度改标准，同模型从第 5 变并列第 1 |
| **反方声音** | 原文标题写「持平=没进步」；核验找到 Chollet、Marcus、Konwinski 的反驳原话 |
| **口径分歧** | 原文只给一个数；核验发现 ARC-AGI-3 有 62.7% / 99.9% / 66% 三个口径 |
| **平衡信息** | 原文自己提过「某些任务会输给竞品」，核验确认后必须补回 |

> 这些内容**必须真正查过才能写**。查不到就留白，不要用推测填。

### 2. 时序梳理

把散落的时间点拉成一条线，本身就是增值。原文可能是「他昨天说……此前还提过……」，
你重排成「7 月启动预训练 → 9/23 首次确认进入后训练 → 官方称希望远早于年底」，读者一眼看懂节奏。

### 3. 影响推演（**必须标为推断**）

可以写「这意味着什么」，但要按用户的事实/推测分栏规则：

- 有来源支撑 → 正常写
- 你的推断 → 写「推测」或「值得观察的是」，不写成既成事实

## 四、发布前的自检四问

1. **把原文和笔记并排，结构一眼能看出不同吗？** 看不出 → 回去重排。
2. **有没有任何一句话是原文的连续 15 字以上？** 有 → 重写这句。
3. **笔记里有没有至少 2 条原文没有的信息？** 没有 → 说明 ③ 核验没做到位。
4. **原文的小标题有没有被直接搬来当卡片标题？** 有 → 换掉，改成读者问题或结论句。

---

## 五、一句话总结

> 顺序由我定、句子由我写、增量靠核验。
> 三条都做到，就不是洗稿；缺任何一条，都还停在改写。

---

## 四、发布前的自检五问（抖音比小红书多一问）

1. **把原文和笔记并排，结构一眼能看出不同吗？** 看不出 → 回去重排。
2. **第 2 张是不是第 1 张的补充说明？** 是 → 换掉，给一个新信息。
3. **每张卡片单独拎出来能看懂吗？** 不能 → 补主语、补上下文。
4. **有没有任何一句话是原文的连续 15 字以上？** 有 → 重写这句。
5. **笔记里有没有至少 2 条原文没有的信息？** 没有 → 说明 ③ 核验没做到位。

---

## 五、一句话总结

> 顺序由我定、**前两张定生死**、句子由我写、增量靠核验。
> 四条都做到，就不是洗稿；缺任何一条，都还停在改写。
